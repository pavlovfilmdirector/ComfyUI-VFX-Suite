# KESHIKI VFX Suite — концепция и план

Рабочий документ. Фиксирует задумку автора и то, что входит в релиз к конкурсу
(дедлайн 30 октября, 9:00 PT / 19:00 МСК), а что уходит в roadmap.

## Принципы

- **В репозитории только код.** Веса не хранятся. В Settings у каждой модели есть
  ссылка на скачивание, можно указать уже существующую папку на диске (без копирования).
- **Процесс можно выключить.** Галочка в Settings: без неё модели не качаются,
  вкладка серая, пайплайн процесс пропускает.
- **Каждый процесс запускается одинаково:** API-JSON → `POST /prompt` в ComfyUI.
  Граф нод в интерфейсе — только превью и редактор параметров этого JSON,
  он не открывает холсты ComfyUI и не копит процессы.
- **Режимы выполнения процесса:** Local / Comfy Partner Nodes (один ключ Comfy API) /
  Custom Workflow / сторонний Cloud API.
- **Тяжёлые инструменты со своими зависимостями** (TRELLIS, Hunyuan3D, SHARP,
  тренеры LoRA) живут в отдельных окружениях и вызываются как внешний процесс.
  В интерфейсе это явно пояснено, указываются путь к `python.exe` и папке инструмента.
- **Интерфейс** по мотивам Blender: горизонтальные вкладки сверху, вертикальные справа,
  всё прижато к линии раздела вьюпорта и рабочей зоны, чтобы меньше водить мышкой.

## Рабочие пространства

| Окно | Назначение |
|---|---|
| **1D** | Изображения: маски, комментарии, пометки отдельными слоями. Слои уходят в генерацию как метаданные/промпты. Кнопки YOLO / SAM2 для выделения объектов. Препроцессы: depth, canny, pose |
| **2D** | Видео: то же без рисования поверх. YOLO / SAM2, CorridorKey, LTX Alpha (пометка «тяжёлый процесс»), линзы, отправка на трекинг. Препроцессы: depth, canny, pose |
| **3D** | Шоты: прилетают трекинг и маски, строится лейаут |
| **3D VFX** | Сцены (именованные, открываются отдельно): полная сборка, рендер clay / с трекерами / со сплатами |

## Вкладки-процессы

- **Agent.** Лёгкая модель всегда в памяти («руки»: запускает процессы),
  тяжёлая подключается для сложных рассуждений — без конфликта двух тяжёлых моделей в VRAM.
  Для облачных моделей ограничение не действует. Агент знает все воркфлоу из `workflows/`
  и базу знаний `core_agent/`, уточняет непонятное, подбирает процесс,
  (опционально) просит подтверждения, составляет промпт и запускает.
- **Storyboard.** Порядок шотов, описания, комментарии. Основа для запуска
  многошотовой сцены или целого фильма; остальные вкладки — настройки этого пайплайна.
- **Character / Location LoRA.** Материал размечается в 1D/2D, датасет собирается
  автоматически под выбранные параметры (размер, длина видео), обучение под капотом.
  LTX-2 (WSL2) — работает; FLUX — с пометкой о требованиях: «на 24 ГБ влезает, но очень медленно».
- **Voice.** Клонирование и озвучка по референсам; синхронный перевод
  (пока только для препродакшена — это указано в интерфейсе). Холст + список персонажей
  с карточками (изображения, видео, голос в разных настроениях).
  Функционал из `video_dubbing_studio`.
- **Video.** Генерация по воркфлоу или своё видео + простая схема нод:
  к видео прикрепляются маски, позы, карты глубины под конкретные воркфлоу.
- **3D Mesh.** Генерация по фото, в стиле интерфейса.
- **Splats.** Генерация (SHARP); лёгкое превью во вьюпорте, настоящий рендер — отдельным процессом.
  В планах: обрезка, перемещение, разделение, анимация частей.
- **Deconstruct.** Обзор всех препроцессов и/или экспорт выбранных слоёв + данных камеры в Nuke.
- **Composite.** Слои + маски → рефайн генерацией, которая сводит слои в один кадр.
  Плюс постпроцессы.
- **Music.** ACE-Step 1.5 — в конце, если останется время.
- **Details.** Карточка любого файла на любом холсте (сейчас только 3D). Стало приоритетом: у каждого
  файла копится свой набор производных элементов, и их нужно видеть и контролировать в одном месте.
  - Состав: слои и маски (1D), видео-слои (2D: depth/canny/pose/маски трекинга/матт), скелеты,
    дети (генерации, препроцессы) и ссылка на родителя, заметки и промпты, история процессов
    (что запускалось, с какой моделью/LoRA/сидом, когда, результат).
  - Действия: переименовать, показать/скрыть, отправить на другой холст или агенту, экспорт
    (PNG/последовательность/видео), удалить с подтверждением, перезапустить процесс с теми же настройками.
  - Метаданные: размер, кадры, fps, путь в проекте, занимаемое место.
- **Монтажный стол** — roadmap.
- **Мессенджер-мост** (`TheHeart_Surreal`): удалённый доступ к агенту и файлам — roadmap.
