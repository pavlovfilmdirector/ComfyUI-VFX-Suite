# Установка KESHIKI VFX Studio (пошагово)

Эта инструкция для тех, кто никогда не работал с командной строкой. Все команды копируются и вставляются как есть.
Подробности на английском, необязательные модули и таблицы моделей: [INSTALL.md](INSTALL.md).

## 1. Что должно быть заранее

- **ComfyUI, который уже запускается и работает.** Найдите его папку: в ней лежат файл `main.py` и папка
  `custom_nodes`. У portable-сборки это `ComfyUI_windows_portable\ComfyUI`.
- **Git.** Скачайте с [git-scm.com](https://git-scm.com/download/win) и установите со всеми настройками по умолчанию.
  Проверка: откройте чёрное окно (шаг 2), напишите `git --version` и нажмите Enter. Должна появиться версия, а не ошибка.
- Видеокарта NVIDIA, лучше 16 ГБ видеопамяти и больше; Windows 10/11.

## 2. Как открыть чёрное окно (командную строку) в нужной папке

1. Откройте в Проводнике папку `custom_nodes` вашего ComfyUI.
2. Кликните в адресную строку сверху (где написан путь), сотрите путь, напишите `cmd` и нажмите **Enter**.
3. Откроется чёрное окно. Строка в нём заканчивается этой папкой, например `D:\ComfyUI\custom_nodes>`.

Вставить текст в чёрное окно: правый клик мышью или Ctrl+V.

## 3. Скачать KESHIKI

Вставьте в чёрное окно и нажмите **Enter**:

```
git clone https://github.com/pavlovfilmdirector/ComfyUI-VFX-Suite.git
```

В `custom_nodes` появится папка `ComfyUI-VFX-Suite`.

## 4. Запустить установщик

Установщик должен работать с тем же Python, которым запускается ваш ComfyUI. Как это сделать, зависит от того,
какой у вас ComfyUI.

### ComfyUI portable

Откройте `custom_nodes\ComfyUI-VFX-Suite` и дважды кликните `install.bat`. Он сам найдёт Python портативной сборки.
Дождитесь надписи `Done.` и нажмите любую клавишу.

### ComfyUI со своим Python (conda, venv, StabilityMatrix, установка через git)

Сначала найдите `python.exe`, которым запускается ComfyUI. Обычно он здесь:

| как установлен ComfyUI | где python.exe |
|---|---|
| окружение conda | `<папка miniconda>\envs\<имя окружения>\python.exe` |
| venv рядом с ComfyUI | `<папка ComfyUI>\venv\Scripts\python.exe` |
| StabilityMatrix | `<папка StabilityMatrix>\Data\Packages\ComfyUI\venv\Scripts\python.exe` |

Не уверены? Откройте в Блокноте `.bat`-файл, которым вы запускаете ComfyUI: в нём написан путь к Python или имя
окружения conda (строка вида `activate.bat ...\envs\ИМЯ`).

**Способ 1 — двойной клик.** Дважды кликните `install.bat`. Он спросит `Path to python.exe:` — вставьте полный путь
из таблицы и нажмите **Enter**. Если KESHIKI лежит не в `custom_nodes`, он спросит ещё папку ComfyUI — вставьте ту,
где лежит `main.py`.

**Способ 2 — командами** (пример для conda; замените пути на свои):

1. Откройте чёрное окно в любой папке (шаг 2).
2. Включите окружение ComfyUI. В начале строки появится его имя в скобках, например `(comfy)`:
   ```
   call D:\miniconda3\Scripts\activate.bat D:\miniconda3\envs\comfy
   ```
3. Перейдите в папку KESHIKI:
   ```
   cd /d D:\ComfyUI\custom_nodes\ComfyUI-VFX-Suite
   ```
4. Сначала проверка — она ничего не меняет, только показывает, что есть и чего не хватает:
   ```
   python install.py --comfy D:\ComfyUI --check
   ```
5. Установка:
   ```
   python install.py --comfy D:\ComfyUI
   ```

### Что пишет установщик

- `ok` — уже установлено;
- `+` — установлено сейчас;
- `MISSING` — ещё нужно; в той же строке написано, что сделать.

Установщик сохраняет пути к ComfyUI и Python в файл `keshiki_local.json`, поэтому дальше вопросов не будет.
Всё, что он написал, сохраняется в `install_log.txt`.

## 5. Модели

Запустите студию (шаг 6). При первом запуске откроется **окно настройки моделей**: в нём видно, что найдено и чего не хватает.

- **Модели уже есть** (в другом ComfyUI или на другом диске): выберите связать папку и укажите папку, в которой лежат
  `checkpoints`, `loras`, `vae` и т. д. Ничего не копируется.
- **Моделей нет:** скачайте их из этого окна или запустите `install.bat --download-models core` (около 40 ГБ).

Окно можно открыть снова из менеджера моделей.

## 6. Запуск

Дважды кликните `run_keshiki_studio.bat` в папке `ComfyUI-VFX-Suite`: он запустит ComfyUI и откроет окно студии.
Можно и по-старому: запустить ComfyUI как обычно и открыть в браузере **http://127.0.0.1:8188/vfx/studio/**.

## 7. Если что-то пошло не так

| сообщение | что делать |
|---|---|
| `'git' is not recognized` | Git не установлен, или чёрное окно открыто до его установки: установите Git, закройте и откройте окно заново. |
| `'python' is not recognized` | Вместо `python` укажите полный путь к `python.exe` (шаг 4). |
| `ComfyUI not found` | Вставьте папку ComfyUI, когда установщик спросит, или добавьте к команде `--comfy <папка ComfyUI>`. |
| красная ошибка в чёрном окне | Сделайте скриншот и пришлите вместе с файлом `install_log.txt` из папки `ComfyUI-VFX-Suite`. |
