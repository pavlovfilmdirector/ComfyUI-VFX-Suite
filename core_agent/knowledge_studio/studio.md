# Архитектура и возможности студии KESHIKI VFX AI Studio

Студия KESHIKI — это локальная среда кинопроизводства, визуальных эффектов (VFX), 3D-лейаута и генеративного звукового продакшна.
Всё работает локально на открытых нейросетевых моделях (GPU). Облачные API выключены по умолчанию (включаются только переменной KESHIKI_ALLOW_CLOUD=1).

---

## 1. Главные рабочие пространства (Окна)

1. **Image (Изображения / 1D)**:
   - Холст создания, инпейнта и многослойного редактирования статичных изображений.
   - Слои рисования кистью с функциональными режимами:
     * «Пометки = указания» (стрелки, надписи, обводки — передаются нейросети как визуальная инструкция правок, в итоговый рендер не попадают).
     * «Эскиз → объекты» (грубый набросок превращается в чистовые фотореалистичные объекты).
     * «Коллаж → вписать» (вставка фото/ассета проекта слоем для бесшовного вписывания по свету и геометрии).
   - Позы и скелеты (DWPose / OpenPose ControlNet), маскирование, карты глубины.
   - Генерация мульти-ракурсных концептов (Multi-Angle Concept / Stitch Reference): генерация объекта или локации с 4 согласованных ракурсов (Front, Side, 3/4, Back) через FLUX/Qwen для последующей круговой сегментации и подачи в 3D.

2. **Video (Видео / 2D)**:
   - Профессиональный VFX-композитинг и генерация видеоряда на базе 22-миллиардной модели LTX-2.5 и LTX-2.3.
   - Работа со слоями видео (Video Layers): исходный плейт, маски, карты глубины, позы, нормали, сгенерированные элементы.
   - Полная деконструкция видео: извлечение чистого фона (Clean Plate), 3D-трекинг камеры (GLOMAP), кеинг волос и тонких контуров (CorridorKey), позы человека, переосвещение (Relight).
   - Таймлайн с покадровым контролем, маркерами In–Out, склейками (монтаж с растворением).

3. **3D VFX & Layout (Сцена и 3D-блокинг)**:
   - Интерактивный трехмерный вьюпорт Three.js для режиссерского блокаута сцены.
   - Расстановка примитивов (прокси-кубов) для задания геометрии, масштабов и взаимного расположения объектов.
   - 6DoF виртуальные кинокамеры: создание траекторий облета (`orbit_half` 180°/360°, `dolly_in`, `truck_right`, `orbit_arc`, вид из свободной камеры).
   - Скелеты персонажей: встроенный стандарт Unreal Engine Mannequin (иерархия костей: Pelvis, Spine, Clavicle, UpperArm, Hand, Thigh, Foot), ретаргетинг анимаций Mixamo/FBX, рендер позы в 2D слой OpenPose через `window.__vfxPoseFrom3D()`.
   - Замена прокси-кубов на чистовые PBR GLB меши из библиотеки с сохранением трансформаций.
   - Запекание сцены в видео: прямой запуск двухстадийного фотореалистичного пайплайна Layout-to-Render.

4. **Аудио, Голос и Музыка (Voice, Dubbing & Music)**:
   - Дубляж и синхронный перевод: распознавание речи (Whisper) → перевод (Ollama LLM) → синтез клонированного голоса (F5-TTS).
   - Клонирование голоса по короткому 5-10 секундному аудиообразцу (`speaker_ref`).
   - Закадровый голос (Narration): длинный текст по абзацам с автоматической склейкой таймингов.
   - Холст озвучки (Voice Board): нодовый граф связи реплик, персонажей и шотов.
   - Липсинк DubIt (LTX-2.3 audio-to-video / маска рта): переозвучка видео с генерацией точного движения губ под новую речь.
   - Генератор музыки ACE-Step 1.5 turbo: создание оригинальных саундтреков, эмбиента и песен по стилям, BPM, тональности и структуре куплетов/припевов.

## 2. Модели и Инструменты

### Изображения (Image):
- **FLUX.3 Klein**: быстрая фотореалистичная генерация (~30–60 с), великолепная работа с текстом, стилями, анатомией и композицией.
- **Qwen-Image-Edit-2511**: превосходное сохранение идентичности персонажа и локации при точечных правках и переосвещении.
- **ControlNet**: управление позе (DWPose), глубине (Depth) и контурам (Canny).
- **LoRA Training**: локальное обучение кастомных LoRA для персонажей, стилей, объектов и локаций в 1 клик.

### Видео (Video) — Движок LTX-2.5 22B:
- Длина видеоряда: квантуется формулой `8n + 1` (9, 17, 25, 33, 49, 65, 81, 97 кадров). Клипы до 97 кадров генерируются за один проход без склеек (~3–4 мин на RTX 3090/4090). Более длинные — чанками с нахлёстом (overlap 16).
- **9 проверенных режимов**:
  1. `t2v` — генерация видео с нуля по тексту (`video_ltx2_5_t2v.json`).
  2. `i2v` — быстрое оживление первого кадра (`video_ltx2_5_i2v.json`).
  3. `pro_i2v` — кинематографичный премиум-рендеринг из картинки с максимальной детализацией (`LTX-2.5_Pro_Image_to_Video.json`).
  4. `flf2v` — интерполяция движения между первым и последним кадром (`video_ltx2_5_flf2v.json`).
  5. `layout_to_render` — фотореалистичный рендер 3D-лейаута и траектории камеры (`LTX-2.5_ICLoRA_Layout_To_Render_Two_Stage_Distilled.json`).
  6. `v2v_ic_lora` — стилистический трансфер видео через управляющие слои (`LTX-2.5_V2V_ICLoRA_Single_Stage_Distilled.json`).
  7. `tiled_fusion_4k` — пространственный тайловый апскейл видео до нативного 4K/8K без переполнения VRAM.
  8. `inpaint_sam2` — замена объектов на видео с трекингом по клику SAM2.
  9. `inpaint_sam3` — семантический инпейнтинг видео по текстовому описанию маски SAM 3.1.
- **Библиотека IC-LoRA весов**:
  - `clean-plate` — удаление людей и движущихся объектов для получения чистого фона.
  - `layout-to-render` — материализация 3D-примитивов в реалистичную сцену.
  - `union-control` — многофункциональный контроль геометрии (поза, контуры, глубина).
  - `refine-details` — полировка артефактов и микродеталей.
  - `day-to-night`, `colorization`, `deblur`, `upscaler-x2`.

### 3D Генераторы и Меши:
- **Microsoft TRELLIS.2-4B**:
  - Высокодетализированная геометрия через каскад разреженных вокселей (O-Voxel) с разрешением 512, 1024 или 1536³.
  - Экспорт чистых PBR GLB файлов с текстурами (Color, Roughness, Metallic, Normal) в разрешении 1024, 2048 или 4096.
  - Режим `generate` (картинка → 3D) и режим `texture` (текстурирование существующей 3D-болванки по референсу).
- **Tencent Hunyuan3D-Omni**:
  - Генерация 3D формы с BBox-conditioning (подгонка пропорций под ограничивающий куб в сцене).
- **Связка с Three.js**:
  - Создание прокси-кубов в сцене → экспорт BBox → генерация меша в TRELLIS.2 → подмена куба на GLB (`replace_proxy_cube`).

### Аудио и Музыка:
- **F5-TTS**: чистый неросетевой синтез речи с точной передачей тембра и эмоций оригинала по 5-10 секундному референсу.
- **Whisper**: мультиязычная расшифровка аудиодорожек с временными метками.
- **Ollama**: локальный перевод текста реплик на нужный язык без облака.
- **DubIt (LTX-2.3)**: перенос речи на лицо персонажа в видео с адаптацией губ под звук.
- **ACE-Step 1.5 turbo**: генерация музыки:
  - Жанры: Cinematic Soundtrack, Epic Orchestral, Cyberpunk Synthwave, Dark Ambient, Trailer Hybrid, Lo-Fi, Rock, Electronic.
  - Настройки: BPM, тональность (Key), размер такта, длина в секундах.
  - Инструментальный трек или вокальная композиция по тегам `[verse]`, `[chorus]`, `[bridge]`, `[outro]`.

## 3. Таблица процессов видео (action video_process: kind + params)

| kind | Что делает | Параметры (params) |
|---|---|---|
| prepare | Раскладка видео на секвенцию кадров (обязательно перед обработкой) | — |
| text_mask | Текстовая сегментация SAM 3.1 | text (англ.: "person", "car", "face"), start, end, source_layer |
| detect_all / detect_yolo | Маски объектов по клику или детекции | engine: "sam2" или "yolo" |
| corridor_key | Чистый кеинг волос и тонких контуров | mask_layer_id |
| ltx_alpha | Генерация альфа-канала без хромакея через LTX Alpha LoRA | start, end |
| depth | Карта глубины | engine: "" (DA V2), "da3" (Depth Anything 3), "depth_pro" (Apple); exclude_mask: убрать фигуру из глубины |
| normal | Карты нормалей геометрии (MoGe-2) | convention: "directx" (Unreal Engine) или "opengl" (Blender/Unity) |
| canny | Контуры Canny для управления геометрией | low_threshold, high_threshold |
| pose | Скелетная поза человека (DWPose / OpenPose) | — |
| track_camera | 3D-трекинг движения камеры GLOMAP/COLMAP | Экспорт траектории в .CHAN |
| first_frame | Генерация ключевого первого кадра под позу и окружение | guide_layer, pose_layer, ref_image, prompt |
| ltx_ic_lora | Видеогенерация LTX с управляющей LoRA | lora ("clean-plate", "layout-to-render", "union-control"), prompt, needs |
| relight_frame | Переосвещение кадра (Qwen Edit 2511) | azimuth (0–360°), elevation (-90..90°), intensity, color (#hex) |
| composite | Сведение слоев с гармонизацией света | fg, mask, bg, harmonize (0.4), light_wrap (0.3), feather |
| montage | Склейка нескольких видео через растворение | videos: [{url}], overlap (кадров) |
| merge_masks | Объединение выбранных масок видео в единый слой | layer_ids, name, color |
| video_cutout | Вырезание объекта по маске на прозрачном альфа-канале (RGBA PNG + WebM) | mask_layer_id, name |
| render | Финальный рендер композиции слоев в видеофайл | — |

## 4. Навигация в интерфейсе студии

- **Центральное меню «✨ Генерация»**: находится по центру вверху над окном предпросмотра на всех вкладках. Содержит разделы: Изображение, Видео, Голос, 3D модель, Музыка, Мои инструменты.
- **Нижний док агента**: строка ввода задач, прикрепление референсов (@теги, медиа-файлы), кнопки быстрой оценки генерации (⭐ / 👍 / 👎) и кнопка «Чат» (`#dock-expand-chat-btn`), открывающая полноэкранную историю.
- **3D Вьюпорт**: тулбар создания примитивов (+Куб, +Камера, +Пол), панель инспектора Details, кнопка спавна скелета UE Mannequin, выбор пресетов облета камеры.
- **Вкладка 2D Видео**: верхний тулбар препроцессов (Маски, Матт, Карты, Линза, Камера) и панель «Блокнот к видео» под таймлайном.

## 5. Главные правила работы ИИ-Режиссера

1. **ПРИНЦИП DOER FIRST:**
   - Никаких вздохов, никаких упаднических рассуждений о «тяжести многошагового процесса».
   - На запрос пользователя отвечай уверенно, формулируй краткий план и **СРАЗУ вызывай исполнительные действия** (`setup_3d_layout`, `mesh3d`, `generate_video`, `dubbing`, `music` и др.).
2. **ПОЛНАЯ АВТОНОМНОСТЬ:**
   - Если пользователь попросил тебя сделать задачу (собрать сцену, сгенерировать 3D меши, сделать клинплейт, озвучить видео) — делай её сам через `actions`, а не посылай пользователя вручную кликать кнопки.
3. **КАЧЕСТВЕННЫЕ КИНЕМАТОГРАФИЧНЫЕ ПРОМПТЫ:**
   - Промпты для FLUX, LTX и TRELLIS пиши по-английски, богато описывая свет, оптику (35mm anamorphic, volumetric haze), материалы (weathered titanium, 8k PBR) и характер движения.
