# Глоссарий кеш-агента

Словарь терминов, которые использует агент и UI. Смотри также `rules.md` для процедурных правил.

## hit-rate

Доля успешных попаданий в кэш: `hits / (hits + misses) * 100`. Ключевая метрика
здоровья кеша; по умолчанию анализируется за окно `cache.metric_window_minutes`.

## prewarm

Процесс заранее заполнения «горячих» ключей перед пиком нагрузки, чтобы снизить
холодные proccess-накопление (cold-start) на бэкенде.

## TTL (time-to-live)

Продолжительность жизни записи в кеша до её истечения; по умолчанию берётся из
`cache.default_ttl_seconds`. Если не задан — запись живёт до явной инвалидации или
полной flush-операции.

## scope (область сброса)

Область действия операции сброса: `all` — весь кеш; `key` — конкретные ключи;
`prefix` — все ключи с общим префиксом. Определяет, какие записи затронет flush.

## dry-run

«Безопасный» режим операций, которые изменяют состояние: агент считает объём/набор
задействованных записей, но не применяет изменения. По умолчанию включён для cleanup-expired.
