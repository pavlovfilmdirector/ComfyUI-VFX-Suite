# LiteRT Local Cache Agent & Orchestrator

Локальная система гибридной оркестрации для управления кэш-агентом. Проект включает в себя реестр сценариев, персистентную базу знаний (Markdown + JSON) и интеллектуальный роутер задач.

## Структура проекта

* `workflow_registry.py` — Реестр воркфлоу (шаг 1): декларативное описание кейсов, параметров и типов.
* `knowledge_base.py` — База знаний (шаг 2): загрузка .md секций, JSON-настроек и полнотекстовый поиск.
* `task_router.py` — Роутер задач (шаг 3): сопоставление интентов, приоритизация параметров (User → БЗ → Default) и аудит ссылок.
* `main.py` — Консольный интерфейс (CLI) для быстрой проверки и отладки.
* `app.py` — HTTP-сервер на базе FastAPI.

## KESHIKI studio agent (v2)

`studio_agent.py` — агент студии, который читает весь разговор и проект, а не одну фразу:

* каталог действий студии (`ACTIONS`): картинка, видео, правка изображения, процессы 2D, деконструкция, музыка, озвучка, граф нод;
* память проекта на диске (`projects/<p>/agent/`): весь диалог, конспект старых разговоров, факты о проекте, действие, ждущее «давай»;
* знания студии — `knowledge_studio/*.md` (роль, модели, правила); их можно дописывать;
* большой контекст: до ~26 тыс. знаков реплик дословно + конспект + факты + состояние проекта, `num_ctx` 24k;
* ответ модели = текст + JSON-решение; тяжёлые действия ждут подтверждения.

Подключён в `/vfx/agent/chat` (по умолчанию `planner: "v2"`, при ошибке — старый режиссёр).
